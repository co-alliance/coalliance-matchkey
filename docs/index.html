CoAlliance Match Key

The Gold Rush MARC match key used by the Colorado Alliance of Research Libraries to identify common bibliographic records across heterogeneous library catalogs. Every match key is exactly 188 characters; the current algorithm version is _v08142026.

The specification is published in three formats. They carry the same content.

  • Read the specification — HTML, rendered in the browser.
  • Read it on GitHub — Markdown, the canonical copy.
  • Download the Word version — .docx, for printing or circulating.
The reference Java implementation, its test suite and porting notes are in the coalliance-matchkey repository.
